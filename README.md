# Лабораторная работа №1. Поточечный график

## Описание
Программа читает несколько наборов точек (x, y) из файла `data.txt`,
сортирует их по x и строит точечный график с помощью Matplotlib.

## Структура проекта
- `data.txt`  — исходные данные (наборы разделены пустой строкой,
                имя набора задаётся строкой, начинающейся с `#`).
- `logic.py`  — чтение и подготовка данных.
- `plot.py`   — построение точечного графика (`scatter`).
- `main.py`   — точка входа, диалог с пользователем.
- `plot.png`  — сохранённый результат.

## Запуск
python main.py
